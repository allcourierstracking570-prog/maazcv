# Maaz Ahmad - Graphic Designer Portfolio

Responsive portfolio website (HTML, CSS, JavaScript).

Pages: Home, Services, Skills, Experience, Contact.

## Photo
Apni photo `images/maaz.jpg` naam se `images` folder me rakh den.

## Contact settings
Email aur WhatsApp number `js/main.js` ke upar `EMAIL` aur `WA_NUMBER` me change kar sakte hain.

## GitHub par upload + free hosting
```bash
cd portfolio
git init
git add .
git commit -m "Initial portfolio website"
git branch -M main
git remote add origin https://github.com/YOUR-USERNAME/portfolio.git
git push -u origin main
```
Phir GitHub repo me: Settings -> Pages -> Branch: `main` / root -> Save.
Website `https://YOUR-USERNAME.github.io/portfolio/` par live ho jayegi.
